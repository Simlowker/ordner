# Demo video script — Ordner (2:00)

Format: 1920×1080 screen capture, English voice-over (local macOS voice, `say -v Daniel`), English subtitles burned in;
the UI stays in French. About 270 words. Production: scripted browser captures of the cockpit (port 8000) and the
agentic conversation (`python -m ordner.harness.web`, port 8790) on the fictional dossier of Noa Keller, simulated date
20.02.2026, Apertus 1.5 8B bf16 served locally; ffmpeg assembles the clips. Every number on screen comes from
`data/results/` or `data/agent_runs/`; dev numbers are labelled "dev".
