## Live commands for 0:22-0:42 (record once, then cut)

These are existing entry points in the code; nothing is staged.

```bash
cd track_2b && export PYTHONPATH=src HF_HUB_OFFLINE=1 && PY=.venv/bin/python
networksetup -getairportpower en0                                  # -> Wi-Fi Power (en0): Off
$PY -m ordner.gen.build --n 1 --seed 99 --out work_demo/           # fresh statement, not in the dataset (seed 7)
$PY -m ordner.pipeline.ocr_batch --work work_demo --shard 0/8      # OCR of one page (s0000-A-p1-d0)
$PY -m ordner.pipeline.extract_batch --work work_demo --tag apertus-lora --adapter work/adapters/lora-v1 --limit 1
tail -1 work_demo/extract.apertus-lora.jsonl | $PY -c "import json,sys; print(json.dumps(json.load(sys.stdin)['fields'], indent=1))"
$PY -c "from ordner.gen.oracle import decode_pdf417, fields_from_xml; print(fields_from_xml(decode_pdf417('work_demo/pdf/s0000-A.pdf')))"
```

Before recording:

- Run the commands once with Wi-Fi on, so the weights are in the local cache, and copy the LoRA adapter from the Mac Studio to `work/adapters/lora-v1`. The extraction script loads `~/ordner/models/apertus-v1.5-8b-text` if it exists, otherwise the Hub cache.
- Close other apps, so that OCR and Apertus run without swapping.
- Use terminal font size 20 and browser zoom 125 %.
