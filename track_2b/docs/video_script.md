# Demo video script — Ordner (1:54)

Format: 1920×1080, H.264 + AAC, 1:54. English voice-over from the local macOS voice (`say -v Daniel`), English subtitles
burned in; the UI stays in French. Production: Playwright recordings (`recordVideo`, 1920×1080) of the cockpit (port 8000)
and of the agentic conversation (`python -m ordner.harness.web --llm openai`, port 8790), on the fictional dossier of Noa
Keller (simulated date 20.02.2026). The conversation uses Apertus 1.5 8B bf16 served locally by `mlx_lm.server`, with the
d1-3B router and no LoRA adapter. Result slides are a local HTML page, screenshotted. ffmpeg puts the clips together. The
cockpit is zoomed to 125 %, the conversation to 120 %, and a red dot stands for the mouse pointer. Every number on screen
comes from `data/results/` or `data/agent_runs/` (test split).

Rules for the recording: no fixture banner on screen; the conversation is a real Apertus session (not the mock), shown
unedited except for the speed-up of the wait, which is labelled, and the answer view, re-opened from the same session (no new model call) to point at the Talbruck line; if a measured number changes, change the slide and the
voice-over, never round in our favour. Distillation numbers are not shown (the distilled coordinator scored below the
base on test).
